# 冻结 V1 的历史留出样本复算

使用发布的 V1 权重复算历史采集掩膜。报告保留样本清单和模型的 SHA-256。将评估输入归一化到 32×32 后，与仓库训练归档做逐像素精确去重检查，三个批次的重合计数均为 0。

| 采集批次 | 输入与标签范围 | 正确数 | 准确率 |
|---|---|---:|---:|
| `thin_mask_validation_09` | 32×32 归一化掩膜，手势 1～5 | 694 / 708 | 98.02% |
| `v3_aligned_01` | 256×144 S5 掩膜，手势 1 | 216 / 288 | 75.00% |
| `v3_aligned_02` | 256×144 S5 掩膜，手势 1 | 275 / 318 | 86.48% |

五类批次按历史清洗规则从 727 张中剔除了 19 张启动和手部入镜过渡样本。手势 1～5 的召回率依次为 98.44%、98.46%、95.08%、99.33% 和 100.00%。该批从已归一化输入开始计分。 [五类留出数据报告](../reports/v1_normalized_holdout.json)

两个 S5 批次合计 491/606，准确率 81.02%。复算从掩膜开始，经过 Python 最大八连通域、32×32 归一化和冻结 V1 整数推理。标签来自原采集记录，统计范围是已保存的掩膜。这些批次包含手势 1，实际连续相机输入的五类识别、定位失败和无手误报需要独立采集。 [单类 S5 回放报告](../reports/v1_aligned_mask_replay.json)

## 在自己的数据上运行

为每段采集准备独立目录，保存掩膜及一份 CSV。`label` 取 0～5，`0` 表示无手。`raw_s5_path` 是相对于 CSV 的 256×144 掩膜文件路径。可选的 `raw_s5_sha256` 用于核验文件。

```csv
label,raw_s5_path
1,masks/frame_001.png
0,masks/frame_002.png
```

```sh
python -m tools.bnn.evaluate_masks scene_a/manifest.csv scene_b/manifest.csv --output build/evaluation.json
```

报告按批次给出混淆矩阵、每类召回率、无有效连通域计数和无手误报率。使用 32×32 已归一化手势掩膜时，改用 `path` 列并加 `--normalized`。已有 `curation.json` 的采集批次可显式加 `--apply-curation`。

实板连续评估时保留人员、场景、光照、帧号与位流 SHA-256。每个序列包含稳定手势、进入、退出和无手片段，再按序列汇总五类召回、定位失败、误报和有效识别帧率。

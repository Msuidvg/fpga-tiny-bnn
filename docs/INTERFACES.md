# 接口与接入约束

## 独立分类核

`gesture_bnn_core` 使用同一时钟域内的 `I_start/O_busy/O_result_valid` 接口。空闲时给出单周期 start，并在 busy 期间保持 `I_mask` 不变。忙时不排队。`I_mask[0]` 对应 32×32 图像行优先顺序的第一个像素；bit 1/0 表示 +1/-1。

默认结构 1024→96→48→5，结果 ID 为 1..5。`O_confidence` 是最大和第二大整数分数之差，饱和到 255，不是校准概率。

权重初始化文件路径由六个 MEM_FILE 参数传入；综合时也必须能访问这些文件。ROM 使用同步读、32-bit 分块，块内低位对应较早输入。源码不依赖厂商原语，跨厂商 RAM 推断及目标时序仍须自行确认。

隐藏层可配置，但固定计数器并不支持任意规模：H1/H2 取 1..511，输入固定 1024 bit、输出固定五类。本项目只提供 V1 96/48 的完整集成基线，其他配置需要重新导出权重与向量并测试。Python 导出器的通用形状支持不等于 RTL 支持任意输入/输出数。

## CCL 与完整管线

`gesture_bnn_pipeline` 输入是 256×144 二值 ROI，不是 RGB 或完整 HDMI 时序。上游需完成肤色分割、4×4 vote 和 3×3 majority，具体参考 `tools/bnn/fpga_preprocess.py`。

- 每帧开始给单周期 `I_frame_start`。
- `I_sample_valid` 带行列坐标与一个 mask bit，相邻有效样本之间至少留三拍空闲周期。
- 每行最后一个有效样本同时给 `I_row_end`，最后一行同时给 `I_final_row`。
- 行末须留足标签清理时间；以随附 testbench 的时序为接入示例，当前接口没有 ready 信号，不能任意压缩消隐间隔。
- 默认 31 个标签、最小连通域面积 80；标签不足由 `O_label_overflow` 报告，该帧不能计作有效检测。
- 正在归一化或推理时不得开始下一帧；等待两个 busy 信号清除后再启动采样。
- 无有效连通域时不会启动新分类，结果消费者必须使用 result_valid，而不能将旧类别当作新结果。

归一化 RAM 和输出掩膜为单帧资源，不提供多帧并发、跨时钟域或输入背压。接入连续摄像头时应在外部增加帧调度和必要缓冲。

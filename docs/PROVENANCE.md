# 来源与许可范围

维护者：Msuidvg。代码从维护者授权整理的 FPGA 手势识别比赛工程提取；逐文件原始相对路径及 SHA-256 见 `source_manifest.json`。

原目录名含 `vendor` 的 gesture 文件在本仓库作为手势处理实现提取，并未复制该目录下的摄像头、DDR、HDMI 或厂商协议栈。保留原模块名以便追溯。

开源整理的主要修改是路径解耦、二值数据归档加载、验证脚本、CI 和文档。四个主要 RTL 文件保持提取时字节一致。历史报告中的机器绝对路径已转换为项目相对路径；历史 SHA 和时间保留。

`data/gesture_v1.npz` 包含 4567 张清洗后的 32×32 二值掩膜、类别、批次和相对样本名，不包含彩色人像、视频、串口记录、联系方式或原始采集设备元数据。2026-10-08 确认的 12 张误采人脸 mask 维持排除，没有为复现旧指标重新放回。训练器原有排除及重标规则在生成此归档前已应用。保留批次身份，支持避免相邻视频帧随机拆分导致的数据泄漏。

`testvectors/pipeline` 包含 204 张二值诊断掩膜及期望计算结果，不用于训练，也不作为正常部署分布的准确率证明。

本仓库提供的代码、模型及二值数据按根目录 MIT 许可证使用；外部工具和库不随本仓库重新许可。公开简历应另行如实说明个人与团队的分工，本仓库存在不等于所有系统代码均由一人独立完成。

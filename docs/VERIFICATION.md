# 验证范围

`python scripts/run_checks.py --rtl` 在当前提取版本上执行：

1. Python 单元测试：二值预处理、舍入、训练抽样、整数阈值、权重导出回读和数据归档加载。
2. 六批清洗后的 4567 张：打包 XNOR-popcount 与独立有符号整数参考逐层比较，并核对冻结模型 SHA-256。历史拟合矩阵使用旧 4579 张数据，与当前清洗集分开记录。
3. 48 组 RTL 核向量：比较各层匹配计数、激活、五类分数、类别、置信差和固定时钟数。
4. 204 组最大连通域：比较 bbox、面积和标签溢出。
5. 204 组 ROI：比较全部 32×32 输出 bit。
6. 204 组整链：从原始 256×144 mask 比较到五类分数、类别与置信差。

`reports/historical_*.json` 是比赛工程历史记录，SHA 对应当时源文件；它们不替代当前版本测试。当前执行日志与 `verification_summary.json` 在 `build/`，也可从 GitHub Actions 下载。

准确率口径：LOBO 为每次完整留出一个真实采集批次；全量拟合为部署模型在训练数据上的正确率；parity 为计算一致性。三者分别报告。

PH1P35 示例补充了分类核和完整管线的综合、布线、静态时序、位流生成及 UART 数据包仿真。示例从板内 ROM 回放掩膜，实板串口验收和连续相机采集待执行。 [构建与 UART 验收说明](../examples/ph1p35/README.md)
